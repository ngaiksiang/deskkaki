# DeskKaki (Astro static site)
- `npm run dev` / `npm run build` / `npm run preview`
- Site URL: `astro.config.mjs` (one line)
- Site name, categories, article list: `src/data/site.ts`
- Products, prices and **affiliate link placeholders**: `src/data/products.ts`
- Articles: `src/pages/articles/*.astro`
- Deploy: see DEPLOY.md
